SelectionList — npaUi Component

Overview

The SelectionList renders a Bootstrap list group where clicking an item fires a select event. It shares the same datasource and adapter model as the Datatable and supports an optional toggle filter input.

Configuration

FieldTypeDescription
datasourceobjectSame descriptor as Datatable (uri, method, adapter, type, manager)
rendererobjectOptional custom renderer: { "type": "MyRenderer" } — class must be loaded and extend ItemRenderer
sorterobjectOptional custom sorter: { "type": "MySorter" } — class must extend ItemSorter
headerobjectOptional header area: { "title": "@list.title" } — also enables the toggle filter input
constraintsobjectOptional height constraint: { "height": { "processor": "$(window).height()-200" } }
stylesheetstringCustom CSS URL; defaults to /uiTools/css/selectionList.css

JavaScript API

let list = npaUi.getComponent('myList');

list.refresh()

Reloads data from the datasource and re-renders the list.

list.load(dataArray)

Loads a local array directly without a REST call.

list.addItem(item)

Appends a single item to the list without a full reload.

list.select(index)

Programmatically selects the item at the given index and fires the select event.

list.getSelectedItem()

Returns the currently selected item, or null if nothing is selected.

list.filter(filterStr)

Filters the visible items by text content (case-insensitive substring match).

list.enable() / list.disable()

Enables or disables click selection.

list.clean()

Clears all items from the list.
