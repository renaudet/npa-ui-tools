DynamicActionLoader — npaUi Component

Overview

The DynamicActionLoader is an invisible component — it renders no HTML. Its sole purpose is to lazily load a JavaScript library and register a global function from that library as the handler for a named npaUi event. Use it to decouple heavy action handlers from the page bootstrap.

Configuration

FieldTypeDescription
actionIdstringThe npaUi event id to handle (registered via npaUi.on())
librarystringURL of the JavaScript library to load (via $.loadScript())
handlerstringName of the global function (exposed on window) in the library to use as the event handler

Example Configuration

{
  "id": "exportLoader",
  "type": "DynamicActionLoader",
  "version": "1.0.0",
  "configuration": {
    "actionId": "export",
    "library": "/my-plugin/js/exportHandler.js",
    "handler": "handleExport"
  }
}
The library is loaded once when the component is first rendered. It must expose the handler as a global function on window:
// exportHandler.js
function handleExport(event) {
  // event is the object passed to npaUi.fireEvent('export', event)
  console.log('exporting...');
}
