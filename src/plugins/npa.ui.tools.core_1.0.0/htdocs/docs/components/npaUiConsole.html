Console — npaUi Component

Overview

The Console is a scrollable, fixed-height text output area. It is used to display logs, command output or any sequential text stream. Text is appended line by line and the console auto-scrolls to the bottom.

Configuration

FieldTypeDescription
heightnumberDisplay height in px; defaults to 300
stylestringAdditional inline CSS appended to the container style

Example Configuration

{
  "id": "outputConsole",
  "type": "Console",
  "version": "1.0.0",
  "configuration": {
    "height": 400
  }
}

JavaScript API

let console = npaUi.getComponent('outputConsole');

console.println(text)

Appends text followed by a line break. Tabs, carriage returns and newlines are converted to HTML equivalents. Auto-scrolls to the bottom.

console.print(text)

Appends text without a trailing line break.

console.clear()

Empties all content from the console.

console.setHeight(height)

Dynamically changes the display height in px.
