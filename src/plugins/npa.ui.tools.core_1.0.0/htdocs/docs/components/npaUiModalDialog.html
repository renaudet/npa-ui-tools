ModalDialog — npaUi Component

Overview

The ModalDialog renders a Bootstrap modal dialog with a header, scrollable body area, and a footer with configurable buttons. Content can be set programmatically or pre-placed as a child div inside the host element.

Configuration

FieldTypeDescription
titlestringDialog title — supports @key i18n
sizestringDialog size: "S" (small), "XL" (large), "XXL" (extra large); default is medium
buttonsarrayFooter button descriptors (see below); if omitted a default Close button is rendered

Button Descriptor

FieldDescription
action"close" (primary blue, dismisses modal) or "cancel" (warning yellow, dismisses modal)
labelButton text — supports @key i18n

Example Configuration

{
  "id": "confirmDialog",
  "type": "ModalDialog",
  "version": "1.0.0",
  "configuration": {
    "title": "@dialog.confirm.title",
    "size": "XL",
    "buttons": [
      { "action": "close", "label": "@dialog.btn.ok" },
      { "action": "cancel", "label": "@dialog.btn.cancel" }
    ]
  }
}

JavaScript API

let dialog = npaUi.getComponent('confirmDialog');

dialog.open()

Opens (shows) the modal dialog.

dialog.close()

Programmatically closes the modal dialog.

dialog.setTitle(title)

Updates the dialog header title. Supports @key i18n.

dialog.setBody(html)

Replaces the modal body content with arbitrary HTML.

Notes

  • The dialog uses data-bs-backdrop="static" — clicking outside the dialog does not dismiss it. Only the declared buttons or programmatic close() can dismiss it.
  • Any child <div> placed inside the host element before rendering is automatically moved into the modal body — useful for embedding a Form component directly.
