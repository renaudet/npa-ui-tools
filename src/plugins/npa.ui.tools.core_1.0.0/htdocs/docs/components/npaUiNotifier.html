Notifier — npaUi Component

Overview

The Notifier renders a Bootstrap Toast container in the top-right corner of the page. It exposes five global convenience functions for displaying transient notifications. The component requires no configuration — it simply anchors the notification area.

Configuration

The Notifier has no configuration fields. A minimal config file:
{
  "id": "notifier",
  "type": "Notifier",
  "version": "1.0.0",
  "configuration": {}
}

Global Notification Functions

Once the Notifier component is rendered on the page, these functions are available globally:
FunctionTypeAuto-hideDescription
showInfo(msg, data)info (blue)noInformational notification, stays until closed
showWarning(msg, data)warning (yellow)noWarning, stays until closed
showError(msg, data)error (red)noError notification, stays until closed
showConfirm(msg, data)confirm (green)4sSuccess confirmation, auto-hides after 4 seconds
flash(msg, data)flash (green)2sBrief flash message, auto-hides after 2 seconds
The msg parameter accepts:
  • A plain string — displayed as-is
  • A string starting with @ — resolved as an i18n key via npaUi.getLocalizedString()
  • A JSON object — pretty-printed automatically
The optional data parameter is an array of substitution values for {0}...{n} placeholders in i18n strings.

Usage Example

// Simple message
showInfo('Record saved.');

// i18n key with substitution
showConfirm('@my.msg.saved', ['myItemName']);

// Display an error response object
showError(response);
