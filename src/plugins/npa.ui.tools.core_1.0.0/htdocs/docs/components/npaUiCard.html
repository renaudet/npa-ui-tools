Card — npaUi Component

Overview

The Card is the standard page container in APAF applications. It renders a Bootstrap card with a coloured header (icon + title), a scrollable working area, and a status bar footer. It automatically stretches to fill the available window height on resize.

Configuration

FieldTypeRequiredDescription
labelstringyesTitle displayed in the header — supports @key i18n references
iconstringyesURL of the icon displayed in the header (16×16 px)
contentDivIdstringnoId of the inner working-area <li> element; defaults to workArea
headerClassstringnoAdditional CSS class for the header; defaults to npa-card-header
stylesheetstringnoCustom CSS URL to load instead of the default /uiTools/css/card.css
heightnumbernoFixed height in px for the working area; if omitted the Card auto-stretches to fill the window

Example Configuration File

{
  "id": "mainCard",
  "type": "Card",
  "version": "1.0.0",
  "configuration": {
    "label": "@my.page.title",
    "icon": "/uiTools/img/silk/application.png",
    "contentDivId": "workArea"
  }
}

JavaScript API

let card = npaUi.getComponent('mainCard');

card.setStatus(text)

Sets the footer status bar text. Pass an empty string or null to clear it. Accepts raw HTML.

card.clearStatus()

Empties the footer status bar.

card.setIcon(iconPath)

Replaces the header icon image with a new URL.

card.setContent(html)

Replaces the entire working-area content with arbitrary HTML.

card.getContentDivId()

Returns the id of the inner working-area element (useful for appending child HTML).

Notes

  • Any HTML child placed inside the Card's host <div> before rendering is detached and re-injected into the working area after the Card structure is built — this allows pre-placing a Splitter or other sub-components inside the Card.
  • The status bar renders a non-breaking space when empty to preserve footer height.
