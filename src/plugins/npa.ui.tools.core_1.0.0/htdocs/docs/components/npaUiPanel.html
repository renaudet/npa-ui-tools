Panel — npaUi Component

Overview

The Panel is the simplest layout container — a plain <div> styled with the npaUiTheme.css. Use it as a transparent wrapper when you need a sized area without any visual frame.

Configuration

FieldTypeDescription
heightnumberOptional fixed height in px; if omitted the panel sizes to its content

Example Configuration

{
  "id": "myPanel",
  "type": "Panel",
  "version": "1.0.0",
  "configuration": {
    "height": 200
  }
}

Notes

  • The Panel renders a <div id="..."> with class panel inside its host element.
  • Unlike the Card, it has no header, footer or status bar — it is purely a layout primitive.
