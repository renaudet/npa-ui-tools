NavBar — npaUi Component

Overview

The NavBar renders a Bootstrap dark navigation bar with a brand icon, application title, and a dynamic menu system. Menus can be defined statically in the configuration file or loaded dynamically from a server endpoint (or both — dynamic items are merged before static ones).

Configuration

FieldTypeRequiredDescription
applicationNamestringyesBrand text — supports @key i18n
iconstringyesURL of the brand icon (30×30 px)
homeRefstringyesURL of the brand link (clicking the icon/title navigates here)
providerUrlstringnoREST endpoint that returns additional menu definitions — merged with menus
menusarraynoStatic top-level menu definitions
stylesheetstringnoCustom CSS URL; defaults to /uiTools/css/navBar.css

Menu Item Structure

Each entry in menus defines a top-level dropdown:
{
  "label": "@menu.help",
  "items": [
    {
      "id": "documentation",
      "label": "@menu.help.docs",
      "actionId": "redirect",
      "uri": "/apaf-documentation/html/documentation.html",
      "newWindow": true,
      "icon": "/uiTools/img/silk/book_open.png"
    },
    { "type": "separator" },
    {
      "id": "about",
      "label": "@menu.help.about",
      "actionId": "showAbout"
    }
  ]
}

Menu Item Fields

FieldDescription
idUnique item identifier, used as the event actionId dispatched via npaUi.fireEvent()
labelDisplay text — supports @key i18n
actionIdAction to fire: "redirect" for navigation, or any custom action registered via npaUi.on()
uriTarget URL (required when actionId is "redirect")
newWindowtrue to open the URI in a new browser tab
iconOptional icon URL shown next to the label
typeSet to "separator" for a visual divider; set to "placeholder" with an id for dynamic injection points

Dynamic Menu Injection

Items marked "type": "placeholder" are injection points that server-side plugins fill at runtime via the apaf.menu.item.provider extension point. This is how APAF plugins (e.g. apaf.documentation) add entries to the Help menu without modifying the static NavBar configuration.
