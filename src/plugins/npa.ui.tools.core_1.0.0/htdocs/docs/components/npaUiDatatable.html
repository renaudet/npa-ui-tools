Datatable — npaUi Component

Overview

The Datatable renders a Bootstrap striped, hoverable table with a sticky header. It fetches its data from a REST endpoint or a DataManager component, and fires a select event when the user clicks a row.

Configuration

FieldTypeDescription
columnsarrayColumn definitions (see below)
datasourceobjectData source descriptor (see below)
maxHeightnumberMaximum table height in px before scrolling
selectionListenerbooleanSet to true to register this component as a listener for another component's selection events
selectionProviderstringId of the component whose selection events this component listens to

Column Descriptor

FieldDescription
fieldName of the data object property to display in this column
labelColumn header text — supports @key i18n; if omitted, field is used
widthOptional fixed column width in px

Datasource Descriptor

FieldDescription
type"local" (REST call, default) or "managed" (DataManager)
uriREST endpoint URI (for local type)
methodHTTP method — defaults to GET
payloadOptional request payload for POST
adapterOptional JS expression to transform the response; use @ as a reference to the response object (e.g. @.data.items)
managerId of the DataManager component (for managed type)

Example Configuration

{
  "id": "myTable",
  "type": "Datatable",
  "version": "1.0.0",
  "configuration": {
    "maxHeight": 400,
    "datasource": {
      "uri": "/my-api/items",
      "adapter": "@.data"
    },
    "columns": [
      { "field": "name", "label": "@col.name", "width": 200 },
      { "field": "version", "label": "@col.version" }
    ]
  }
}

JavaScript API

let table = npaUi.getComponent('myTable');

table.refresh()

Reloads data from the datasource and re-renders the table.

table.setData(dataArray)

Sets the table content to a locally provided array without making a REST call.

Row selection

When the user clicks a row, the Datatable fires a select event with the clicked item:
npaUi.on('select', function(event) {
  if (event.source === 'myTable') {
    let selectedItem = event.item;
  }
});
Components that set selectionListener: true and selectionProvider: "myTable" in their configuration will have their onItemSelected(item) method called automatically.
