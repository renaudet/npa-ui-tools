Form — npaUi Component

Overview

The Form component renders a data-entry form from a declarative field list. It supports read-only and edit modes, multiple field types, client-side validation via constraint expressions, and fires form events when field values change.

Configuration

FieldTypeDescription
fieldsarrayList of field descriptors (see below)
selectionListenerbooleanWhen true, the form listens for selection events from selectionProvider and calls setData() automatically
selectionProviderstringId of the source component

Field Descriptor

FieldDescription
nameProperty name in the data object — also used as the field's DOM id base
labelDisplay label — supports @key i18n
typeField type: text, password, textarea, integer, float, boolean, select, date, custom
sizeBootstrap column width (1–10); defaults to 10
mandatoryMarks the field as required (red asterisk)
isIdFieldMarks this field as the record id (displayed with a red asterisk)
readOnlyField is always read-only regardless of form edit mode
constraintJS expression evaluated on form events; use @ for the data object and # for the field instance
constrainedById of another field that triggers this field's constraint evaluation

Example Configuration

{
  "id": "myForm",
  "type": "Form",
  "version": "1.0.0",
  "configuration": {
    "selectionListener": true,
    "selectionProvider": "myTable",
    "fields": [
      { "name": "id", "label": "@field.id", "type": "text", "isIdField": true },
      { "name": "name", "label": "@field.name", "type": "text", "mandatory": true },
      { "name": "active", "label": "@field.active", "type": "boolean" }
    ]
  }
}

JavaScript API

let form = npaUi.getComponent('myForm');

form.setData(dataObject)

Populates the form fields with the values from dataObject.

form.getData()

Returns an object with the current values of all form fields.

form.setEditMode(editable)

Switches the form between read-only (false) and edit (true) mode. In read-only mode all input fields are disabled.

form.checkForm()

Returns true if all mandatory fields are filled and no field has raised a veto.

Notes

  • When selectionListener: true is set, the form automatically calls setData(selectedItem) whenever the user selects a row in the linked component.
  • Constraint expressions are evaluated in the context of the current form data (@) and the field instance (#), allowing show/hide/enable logic such as "#.setEnabled(@.type === 'advanced')".
