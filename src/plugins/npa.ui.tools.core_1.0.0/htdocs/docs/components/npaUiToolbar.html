Toolbar — npaUi Component

Overview

The Toolbar renders a horizontal row of icon buttons. Each button dispatches an event via npaUi.fireEvent() when clicked. Buttons can be statically defined, conditionally shown/hidden, or include a text filter input control.

Configuration

FieldTypeDescription
actionsarrayList of button descriptors (see below)
pluggableActionHandlersarrayOptional list of pluggable handler configs for dynamic action delegation

Action Descriptor Fields

FieldDescription
actionIdEvent id dispatched on click; also used as the button's DOM id suffix
labelTooltip text — supports @key i18n
iconURL of the button icon
symbolText symbol rendered inside the button (alternative to icon)
enabledSet to false to render the button initially disabled
type"separator" for a visual divider; "conditional" to render hidden by default; "control" with "kind": "filter" for a text input+button combo

Example Configuration

{
  "id": "myToolbar",
  "type": "Toolbar",
  "version": "1.0.0",
  "configuration": {
    "actions": [
      { "actionId": "refresh", "icon": "/uiTools/img/silk/arrow_refresh.png", "label": "@toolbar.refresh" },
      { "type": "separator" },
      { "actionId": "delete", "icon": "/uiTools/img/silk/delete.png", "label": "@toolbar.delete", "type": "conditional" }
    ]
  }
}

JavaScript API

let toolbar = npaUi.getComponent('myToolbar');

toolbar.setEnabled(actionId, enabled)

Enables or disables the button with the given actionId.

toolbar.show(actionId) / toolbar.hide(actionId)

Shows or hides a conditional button.

Handling button clicks

Register a handler via npaUi.on():
npaUi.on('refresh', function(event) {
  loadData();
});

npaUi.on('delete', function(event) {
  deleteSelected();
});
