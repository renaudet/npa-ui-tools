VerticalMenu — npaUi Component

Overview

The VerticalMenu renders a two-column layout: a narrow left column with a Bootstrap nav flex-column menu, and a wide right content area. Clicking a menu item reveals its associated content div and hides all others. A menu.item.selected event is fired on each selection.

Configuration

FieldTypeDescription
itemsarrayMenu item descriptors (see below)
expandsTostringId of a parent element; the menu height tracks its parent on resize

Item Descriptor

FieldDescription
idUnique item id — matches the data-menu-ref attribute on child content divs
labelMenu item text — supports @key i18n
activeSet to false to disable this item; defaults to true

HTML Structure

Pre-place content divs with data-menu-ref matching each item's id:
<div class="npaUi" id="myMenu" data-config="/my/menuConfig.json">
  <div data-menu-ref="page1"><p>Page 1 content</p></div>
  <div data-menu-ref="page2"><p>Page 2 content</p></div>
</div>
The first item's content is visible by default; all others are hidden.

JavaScript API

let menu = npaUi.getComponent('myMenu');

menu.addMenuItem(id, label, htmlContent)

Dynamically adds a new item to the menu and injects its HTML content into the content area.
