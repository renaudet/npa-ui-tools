HtmlImport — npaUi Component

Overview

The HtmlImport fetches an HTML fragment from a URL and appends it into the component's host element. It is a simple inclusion mechanism — useful for injecting server-rendered or static HTML partials into a page without a full page reload.

Configuration

FieldTypeDescription
urlstringURL of the HTML fragment to load (absolute or relative)
stylesheetstringOptional CSS URL to load before the fragment is rendered

Example Configuration

{
  "id": "myImport",
  "type": "HtmlImport",
  "version": "1.0.0",
  "configuration": {
    "url": "/my-plugin/html/partial.html"
  }
}

Notes

  • The fragment is loaded once — on subsequent npaUi.render() calls the component is skipped (host div is already marked as loaded).
  • The fetched content is appended (not replaced) into the host div.
  • No script tags in the imported fragment are executed — use this for HTML structure only.
