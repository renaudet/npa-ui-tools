TabPane — npaUi Component

Overview

The TabPane renders a Bootstrap tabbed interface. Each tab has a labelled button in the header and a dedicated content pane. Child npaUi components can be pre-placed in each pane using the data-tab-target HTML attribute.

Configuration

FieldTypeDescription
tabsarrayTab descriptors (see below)
parentIdstringOptional — id of the parent element; when set, the TabPane constrains its height to fit inside it

Tab Descriptor

FieldDescription
idUnique tab id — also used as the pane DOM id (suffix _pane)
labelTab header text — supports @key i18n
activeSet to false to render this tab disabled; defaults to true

HTML Structure

Pre-place npaUi components in a tab by setting data-tab-target to the tab's id:
<div class="npaUi" id="myTabs" data-config="/my/tabsConfig.json">
  <div data-tab-target="tab1">
    <div class="npaUi" data-config="/my/tab1Content.json"></div>
  </div>
  <div data-tab-target="tab2">
    <div class="npaUi" data-config="/my/tab2Content.json"></div>
  </div>
</div>

JavaScript API

let tabs = npaUi.getComponent('myTabs');

tabs.addTabEventListener(tabId, listener)

Registers a callback function to be called when the tab with the given id is clicked/shown.
