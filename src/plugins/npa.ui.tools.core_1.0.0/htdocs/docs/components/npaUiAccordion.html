Accordion — npaUi Component

Overview

The Accordion renders a Bootstrap accordion (collapsible sections). Only one section is expanded at a time. Child npaUi components can be placed in each section using the data-section HTML attribute.

Configuration

FieldTypeDescription
sectionsarraySection descriptors (see below)
stylesheetstringCustom CSS URL; defaults to /uiTools/css/accordion.css

Section Descriptor

FieldDescription
idUnique section id — used as the pane DOM id suffix and to match data-section on child divs
labelSection header text (supports @key i18n)

HTML Structure

Pre-place child content in each section using data-section on a child <div>:
<div class="npaUi" id="myAccordion" data-config="/my/accordionConfig.json">
  <div data-section="section1">
    <div class="npaUi" data-config="/my/section1Content.json"></div>
  </div>
  <div data-section="section2">
    <div class="npaUi" data-config="/my/section2Content.json"></div>
  </div>
</div>
The first section is expanded by default. Child components inside sections are rendered with an 800ms delay to allow Bootstrap's collapse animation to complete before npaUi.render() scans for sub-component tags.
