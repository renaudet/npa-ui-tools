Carousel — npaUi Component

Overview

The Carousel renders a Bootstrap slide carousel with Previous/Next navigation arrows. Each slide hosts a child div placed with the data-slide-id HTML attribute. The carousel can optionally auto-play and use a fade transition.

Configuration

FieldTypeDescription
transitionStylestringSet to "fade" for a cross-fade transition; omit for the default slide
autoPlaybooleanWhen true, the carousel cycles automatically (data-bs-ride="carousel")
expandsTostringId of a parent element to match height against (carousel inner height = parent height − 30px), with responsive resize on window resize
stylesheetstringCustom CSS URL; defaults to /uiTools/css/carousel.css

HTML Structure

Place child divs with data-slide-id inside the host element:
<div class="npaUi" id="myCarousel" data-config="/my/carouselConfig.json">
  <div data-slide-id="slide1"><p>Slide 1 content</p></div>
  <div data-slide-id="slide2"><p>Slide 2 content</p></div>
</div>
Each slide is centred in a 8-column Bootstrap grid (col-2 / col-8 / col-2 layout). The first slide is active by default.

Notes

  • Slide ids must be unique across the page as they are used as DOM element ids.
  • The expandsTo option is useful when the carousel is inside a Card or Panel of a known id — the carousel inner area will track its height on window resize.
