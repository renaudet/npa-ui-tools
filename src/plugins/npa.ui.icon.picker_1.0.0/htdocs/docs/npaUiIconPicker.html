IconPicker — npaUi Component

Overview

The IconPicker is provided by the npa.ui.icon.picker plugin under the npaIconPicker namespace. It behaves like an HTML file selector: a read-only field displays the path of the selected icon, with a 16x16 (or 32x32) preview, and a Browse... button opens a modal dialog presenting the available icons visually. Sub-directories of the plugin's htdocs/img folder are displayed as folders: click a folder to open it, use the breadcrumb or the parent button to go back. A filter field narrows the icons displayed in the current folder. Double-click an icon to select it immediately.

Icon packs

Icons are discovered dynamically at runtime by scanning the htdocs/img folder of the plugin (npa.ui.icon.picker_x.y.z/htdocs/img). To add an icon pack, simply drop a new folder (e.g. htdocs/img/mypack) containing icon files: no configuration file, manifest or code needs to be modified. Supported file types: png, gif, jpg, jpeg, svg, ico, webp. The plugin initially ships the silk pack. Selected values are public URIs such as /npaIconPicker/img/silk/application.png.

Example Configuration

{
  "id": "myIcon",
  "type": "npaIconPicker.IconPicker",
  "version": "1.0.0",
  "configuration": {
    "value": "/npaIconPicker/img/silk/application.png",
    "previewSize": 16
  }
}

JavaScript API

MethodDescription
getValue()Returns the selected icon path (empty string if none)
setValue(path, notify=false)Sets the icon path, updates the preview; calls the change listeners when notify is true
onChange(callback)Registers a listener called with the new value each time the user changes the selection
setEnabled(boolean)Enables or disables the Browse and Clear buttons
open()Opens the selection dialog programmatically

Usage in a dynamic APAF application

let card = $apaf('genericApplicationsCard');
card.setContent('<div id="iconDiv" class="user-app" data-ref="myIcon"></div>');
npaUi.registerComponentConfig('myIcon', { id: 'myIcon', type: 'npaIconPicker.IconPicker', version: '1.0.0', configuration: {} });
npaUi.render('user-app');
// later: npaUi.getComponent('myIcon').getValue()

Usage as a Form field ('icon' datatype)

The plugin also contributes a specialized pluggable field editor for the Form component (npaUiCore.Form) for fields of type icon:
{
  "name": "icon",
  "label": "Icon",
  "type": "icon",
  "placeholder": "@npa.ui.icon.picker.placeholder",
  "previewSize": 16,
  "help": "Select an icon"
}

REST API

MethodURIDescription
GET/npaIconPickerApis/icons?path=<folder>Lists the sub-folders and icon files of htdocs/img/<folder>. The path parameter is relative to htdocs/img (default: root). Paths trying to leave htdocs/img are rejected with status 400.

Extension points

  • npa.ui.tools.core.component: Registers the standalone component with namespace npaIconPicker and name IconPicker.
  • npa.ui.tools.core.editor: Registers the pluggable form field editor for datatype icon with class npaIconPicker.IconFormFieldEditor.
